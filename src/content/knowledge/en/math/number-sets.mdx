# Number sets

Number sets classify numbers according to their properties.

| Symbol | Name | Examples |
| --- | --- | --- |
| $\mathbb N$ | natural numbers | $0,1,2,3,\ldots$ |
| $\mathbb Z$ | integers | $\ldots,-2,-1,0,1,2,\ldots$ |
| $\mathbb D$ | finite decimals | $0.5$; $-2.75$; $10.01$ |
| $\mathbb Q$ | rational numbers | $\frac13$; $-\frac72$; $0.5$ |
| $\mathbb R$ | real numbers | $\pi$; $\sqrt2$; $\frac13$; $-5$ |
| $\mathbb C$ | complex numbers | $2+3i$ |

<Formula title="Set inclusions" wide>

  $$
  \mathbb N\subset\mathbb Z\subset\mathbb D\subset
  \mathbb Q\subset\mathbb R\subset\mathbb C
  $$

</Formula>

<Grid>
  <Definition title="Membership">
    $x\in A$ means that the number $x$ is an **element** of set $A$.
    For example, $5\in\mathbb N$.
  </Definition>

  <Definition title="Inclusion">
    $A\subset B$ means that every element of set $A$ also belongs to set $B$.
    For example, $\mathbb N\subset\mathbb Z$.
  </Definition>

  <CommonMistake title="Element or set?">
    Write **number $\in$ set**, but **set $\subset$ set**. Thus,
    $5\in\mathbb N$ and $\mathbb N\subset\mathbb Z$.
  </CommonMistake>

  <Note title="Two conventions to check">
    Here, $0\in\mathbb N$. Some courses start the natural numbers at $1$.
    Also, $\mathbb D$ is mainly used in French-speaking curricula and is not
    a universal English-language notation.
  </Note>
</Grid>

<Summary>
  Memorize the inclusion chain, then the distinction between $\in$ (an element
  belongs to a set) and $\subset$ (one set is included in another).
</Summary>
