# Symboles logiques

Ces symboles permettent d'écrire précisément des affirmations mathématiques.

<Grid title="Table des symboles">
  <DataTable wide compact lines="rows">

    | Symbole | Lecture | Exemple |
    | --- | --- | --- |
    | $\in$ | appartient à | $5\in\mathbb N$ |
    | $\notin$ | n'appartient pas à | $-2\notin\mathbb N$ |
    | $\subset$ | est inclus dans | $\mathbb N\subset\mathbb Z$ |
    | $\not\subset$ | n'est pas inclus dans | $\mathbb R\not\subset\mathbb Q$ |
    | $\forall$ | pour tout | $\forall n\in\mathbb N$ |
    | $\exists$ | il existe | $\exists x\in\mathbb R$ |
    | $\nexists$ | il n'existe pas | $\nexists x\in\mathbb R:x^2=-1$ |
    | $\Rightarrow$ | implique | $x>2\Rightarrow x>1$ |
    | $\Leftrightarrow$ | équivaut à | $x^2=4\Leftrightarrow x=\pm2$ |
    | $\ne$ | différent de | $2\ne3$ |
    | $\leq$ | inférieur ou égal | $x\leq5$ |
    | $\geq$ | supérieur ou égal | $x\geq0$ |

  </DataTable>
</Grid>

<Grid title="Lire les affirmations logiques">
  <Example title="Lire une définition de suite">
    $$\forall n\in\mathbb N,\qquad u_n=2n+1$$
    se lit : « Pour tout entier naturel $n$, le terme de rang $n$ vaut
    $2n+1$. » Ici, $n$ est le rang et $u_n$ est le terme correspondant.
  </Example>

  <Definition title="Implication">
    $P\Rightarrow Q$ affirme que si $P$ est vraie, alors $Q$ est vraie.
    Cela ne garantit pas que $Q\Rightarrow P$.
  </Definition>

  <Definition title="Équivalence">
    $P\Leftrightarrow Q$ signifie que les deux implications
    $P\Rightarrow Q$ et $Q\Rightarrow P$ sont vraies.
  </Definition>

  <CommonMistake>
    $\Rightarrow$ et $\Leftrightarrow$ ne sont pas interchangeables.
    Par exemple, $x=2\Rightarrow x^2=4$, mais $x^2=4$ n'implique pas $x=2$
    puisque $x$ peut aussi valoir $-2$.
  </CommonMistake>
</Grid>

<Grid>
  <Summary>
    Les quatre idées prioritaires sont : les inclusions d'ensembles,
    $x\in\mathbb R$, $\forall$ (« pour tout ») et $\exists$ (« il existe »).
  </Summary>
</Grid>
